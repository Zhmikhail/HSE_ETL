# YQL-скрипты для RUvideos.csv

Файл `RUvideos.csv` содержит повторяющиеся значения `(video_id, trending_date)`,
поэтому в таблице YDB используется технический первичный ключ `row_id`. Перед
импортом CSV в YDB нужно добавить колонку `row_id` с последовательными целыми
значениями, начиная с `1`.

Порядок запуска:

1. `01_create_ruvideos_raw.yql` - создает сырую таблицу для импорта CSV.
2. Импортировать подготовленный CSV-файл в таблицу `ru_videos_raw`.
3. `02_check_ruvideos_raw.yql` - проверяет количество строк и базовые агрегаты.
4. `03_create_category_stats.yql` - создает агрегированную таблицу по категориям.
5. `04_create_daily_stats.yql` - создает агрегированную таблицу по дням.
